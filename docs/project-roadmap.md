# Project Roadmap

## Project Name

Chaos Engineering Sandbox

## Project Purpose

This project demonstrates resilience engineering through controlled failure testing in a microservices environment.

The goal is to build a realistic DevOps and Cloud Support portfolio project that shows how a system behaves under failure, how it is monitored, and how it can be improved.

## Core Milestones

### 1. Architecture Design

Design the system architecture, including:

- Microservices
- Docker containers
- Kubernetes cluster
- Observability stack
- Chaos engineering tool

### 2. Microservices Deployment

Build and deploy a small application made of multiple services:

- Frontend
- Backend API
- Database
- Cache

### 3. Chaos Experiments

Run controlled failure experiments such as:

- API pod kill
- Cache failure
- Database failure
- Network latency
- CPU stress
- Memory stress

### 4. Observability Dashboards

Use monitoring tools to observe system behavior:

- Prometheus
- Grafana
- Kubernetes metrics
- Application health endpoints

### 5. Case Study Report

Document the results of each experiment:

- What was tested
- What failed
- How the system responded
- How long recovery took
- What improvements were made

## Final Portfolio Outcome

The final repository should show:

- Working application code
- Docker configuration
- Kubernetes manifests
- Monitoring setup
- Chaos experiment files
- Screenshots
- Incident-style reports
- Lessons learned
